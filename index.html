Integrasi Google Sheets Gratis

Kamu tidak perlu sewa database berbayar! Nilai murid bisa langsung masuk otomatis ke Google Spreadsheet di Google Drive kamu secara gratis:

  1. Buat Google Spreadsheet baru di Google Drive kamu.
  2. Klik menu Extensions (Ekstensi) > Apps Script, hapus kode lama, lalu paste script ini:
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); sheet.appendRow([ new Date(), data.studentName, data.studentClass, data.score, data.correctCount + "/15", JSON.stringify(data.answers) ]); return ContentService.createTextOutput(JSON.stringify({"status":"success"})) .setMimeType(ContentService.MimeType.JSON); }
  1. Klik Deploy > New deployment, pilih Web App, atur akses ke Anyone, lalu salin URL Web App yang didapat.
